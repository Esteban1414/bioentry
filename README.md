# BioEntry

This is a Django-based web dashboard for managing and analyzing user access data for the BioEntry system. It includes a clean admin panel, real-time notifications, and a heatmap visualization of activity peaks.


## Technologies

- [Django](https://www.djangoproject.com/)
- [MySQL](https://www.mysql.com/).
 - [Seaborn](https://seaborn.pydata.org/) + [Matplotlib](https://matplotlib.org/) (heatmap )
